# 商店与官网资料草案

## 名称

Band Room — 乐队排练同步助手

## 一句话介绍

一台设备控制伴奏与曲谱，乐手用浏览器在同一局域网同步查看自己的轨道。

## 简短介绍

Band Room 可在 Mac、Windows 或 Android 主机上创建排练房间，读取常见 GP 曲谱格式并播放伴奏。乐手无需安装 App，只需扫描二维码，即可在手机或平板上选择自己的轨道，同步查看小节、拍点、游标与自动滚动。

## 核心卖点

- 主机是唯一时间源，播放、暂停、跳转和速度变化同步。
- 每位乐手只选择并查看自己的轨道。
- 局域网运行，排练过程不依赖公网。
- 支持 Mac、Windows、Android 主机与常见移动浏览器。
- 用户自行导入曲谱；软件不附带歌曲或商业曲库。

## 必须展示的信息

- 当前版本和支持的系统版本。
- 价格、试用范围、升级期限和退款规则。
- 下载大小与 SHA-256。
- 隐私政策、源代码、第三方许可证和支持入口。
- “Guitar Pro 是 Arobas Music 的商标；Band Room 与其无关联”的兼容性声明。

## 截图清单

- 主机创建房间与二维码。
- 主机曲谱、伴奏和播放控制。
- 手机选择轨道。
- 手机同步游标与自动滚动。
- Mac、Windows、Android 三种主机外观。
