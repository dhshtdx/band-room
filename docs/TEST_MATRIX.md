# 发布测试矩阵

每项记录版本、日期、测试人、设备、系统、网络环境、结果和问题编号。
因为本项目不签名、不公证，测试重点放在"未签名包能不能被正常放行"和"同步是否可靠"上。

## 必测平台

- macOS Apple Silicon：当前系统及前一主要版本。
- macOS Intel：至少一台真实 Intel Mac（构建已产出 Universal 包，但需实机确认）。
- Windows 11 与 Windows 10 x64。
- 加入端：iPhone Safari、iPad Safari、Android Chrome、桌面 Chrome/Edge。

## 主流程

- 首次安装、升级覆盖、卸载、再次安装。
- **未签名放行**：首次打开时右键打开 / `xattr -dr com.apple.quarantine` 能成功进入；README 描述与实际提示一致。
- 创建房间一次成功，二维码只含 `/join?room=`，不含主机令牌。
- 2、5、10 台设备加入；成员加入、刷新、断网、重连和离开状态正确。
- 加载 `.gp/.gp3/.gp4/.gp5/.gpx`，非法扩展、损坏文件和超过 20 MB 文件被拒绝。
- 每台设备独立选择轨道，乐手端无伴奏输出。
- 主机准备伴奏后有声；切换系统输出设备后仍可恢复。
- 播放、暂停和跳转均一次生效；连续快速操作不反转状态。
- 固定速度、变速、反复和跳房子曲谱的绝对 tick、小节、拍点与 AlphaTab 一致。
- 乐手端游标、音符高亮和自动滚动跟随；手动滚动时不出现异常回弹。
- 连续播放 60 分钟，位置不持续漂移，内存不无限增长。

## 网络与恢复

- 无公网但有局域网时完整运行。
- 主机切换 Wi‑Fi 后重新创建房间并显示正确地址。
- 乐手设备锁屏 2 分钟、切后台、关闭再打开浏览器后恢复。
- 路由器短暂断开 10 秒后自动重连。
- 公共 Wi‑Fi 客户端隔离时给出明确说明，而不是假装连接成功。
- Windows/macOS 防火墙首次提示和再次启动行为明确。

## 安全与隐私

- 乐手端无法创建、上传、播放、暂停或跳转。
- 伪造/缺失 hostToken 得到 `HOST_AUTH_INVALID`。
- 房间达到 32 台设备后拒绝新设备，但同一 clientId 可重连。
- 超大 WebSocket 消息被断开且主机继续服务。
- 法律页面离线可打开，"获取本版本对应源代码"链接指向真实仓库。
- 正常退出后临时曲谱被删除；安装包和日志不含测试曲谱或密钥。
- 确认 `pnpm audit --prod` 为 0 个已知漏洞。
